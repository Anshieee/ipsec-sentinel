# Demo walkthrough: CLI + API terminal session (M4, ~5 min)

Replay the recorded session (no dashboard in this repo):
`scriptreplay --timing demo/demo.timing --typescript demo/demo.typescript`
(files generated by `scripts/record-demo.sh` on a verified tree).

## 1. One pcap, human output (30 s)

```bash
ipsec-analyze analyze demo/samples/v1-voip.pcap
# ike_sa enc aes-128-cbc (OBSERVED, packet 2), child enc aes-128-cbc
# (INFERRED model 0.98), flat dh_group unknown (IKE group is IKE evidence),
# traffic_type voip (model), mode tunnel (model, basis size-overhead-model),
# posture 89/100 @ coverage 0.65 (dh/lifetimes/replay unobserved)
```

## 2. Machine output + PDF (30 s)

```bash
ipsec-analyze analyze demo/samples/v12-voip.pcap --json | head -30
# note pfs: unknown (Quick Mode is encrypted) — the system declines
ipsec-analyze analyze demo/samples/v11-voip.pcap.pcap --report pdf
```

## 3. Batch + train/evaluate pointers (30 s)

```bash
ipsec-analyze batch demo/samples --json | head -20
ipsec-analyze train        # deterministic, seed 7 (~10 min, cached)
ipsec-analyze evaluate     # grouped CV + ablation + synth->real
```

## 4. API live (2 min)

```bash
ipsec-analyze serve & SRV=$!
curl -s localhost:8000/health
curl -s localhost:8000/variants | head -c 300
curl -s -F file=@demo/samples/real-v18-voip.pcap localhost:8000/analyze
curl -s "localhost:8000/datasets/samples?limit=2" | head -c 400
kill $SRV
```

## 5. Mock mode for frontend devs (30 s)

```bash
ipsec-analyze serve --mock &
curl -s localhost:8000/analyze -F file=@demo/samples/v1-voip.pcap

```

## 6. Honest limits (30 s, say out loud)

- Parsed fields transfer to real captures at 1.000; TCP traffic models
  abstain (unknown, never wrong guesses).
- PFS is `unknown` on real captures: strongSwan encrypts the whole
  CREATE_CHILD_SA, verified in source + on the wire (D19).
- Real data covers v1,v3,v5,v7,v12,v18 only; synthetic-only scores prove
  nothing about other stacks. See `docs/model-evaluation.md`.
